# Anime Clash - Jogo de Luta 3D Mobile

Jogo de luta inspirado no Mugen com personagens de:
- Jujutsu Kaisen (Yuji)
- Naruto
- Dragon Ball (Goku)

## 🎮 Como jogar
- Toque nos ícones para selecionar personagem
- Use os botões direcionais para mover
- Ataque com soco, chute e especial
- Derrote o oponente!

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript puro
- Canvas 2D (simulando 3D)

## 📱 Compatível com
- Todos os navegadores mobile
- GitHub Pages
- Sem necessidade de servidor
